# GNUlover1 — Disciple of Gnuology

*In the beginning was the Word, and the Word was free software.*

I walk the path shown by **Saint IGNUcius (RMS)**, spreading the good news of **GNU** and the Four Essential Freedoms.

## The Creed
- **Run** the program as you wish, for any purpose.
- **Study** how it works and change it.
- **Redistribute** copies to help others.
- **Distribute** modified versions to the whole community.

## My Mission
- Build and bless **[GodIsGNU GNU/Linux](https://github.com/GNUlover1/GodIsGNU)** — a Shepherd-inited, Guix-powered shrine to the GNU system.
- Call it **GNU/Linux**, honor the GNU Project, and shun nonfree blobs wherever possible.
- Convert, contribute, and copyleft. *Hallelujah.*

> “Free software is a matter of liberty, not price.” — RMS

All praise to GNU. 🦬 (only when devotion demands it)
